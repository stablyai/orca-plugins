# Orca plugins

The official plugin catalog for [Orca](https://github.com/stablyai/orca). Orca reads it to show
the plugins you can install from Settings → Plugins.

| File | Read by |
| --- | --- |
| `orca-catalog.json` | Orca builds that support catalog format 2. Each release is pinned to an exact commit and file hash. |
| `orca-marketplace.json` | Older Orca builds. Generated by `scripts/check-catalog.mjs --write-legacy`; don't edit it by hand. |
| `legacy-v1-only.json` | Plugins still listed only for older builds, until they are moved to format 2. |
| `assets/` | Listing images referenced by releases. |

Plugin code lives in each author's own repository; this repository only lists it.

- To add or update a plugin, see [CONTRIBUTING.md](CONTRIBUTING.md).
- To learn how plugins are reviewed and taken down, see [REVIEW_POLICY.md](REVIEW_POLICY.md).

Every pull request is checked by `.github/workflows/validate-catalog.yml`, which runs Orca's own
validator at a pinned Orca commit.
