# VS Code Default Themes for Orca

- VS Code Dark+ (dark, with a matching terminal theme)
- VS Code Dark Modern (dark)
- VS Code Light+ (light)
- VS Code Light Modern (light)

Choose a theme under Settings → Appearance.

## Attribution

Converted from the VS Code color theme [Default Themes](https://github.com/microsoft/vscode/tree/main/extensions/theme-defaults) with `tools/import-vscode-theme` in
[stablyai/orca-plugins](https://github.com/stablyai/orca-plugins). The upstream license notice is kept in [LICENSE](LICENSE).

VS Code Dark+ also sets the workbench colors that VS Code supplies in code rather than in its theme
file (buttons, sidebar, focus ring, muted text, hover), and ships VS Code's default dark terminal
palette as a terminal theme. The other themes use Orca's default terminal colors.
